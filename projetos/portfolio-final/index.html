Projeto final de portfólio

Escolha um problema real, planeje, construa, teste, publique e documente — do zero ao link.

RequisitosArquiteturaTestesPublicaçãoDocumentação

Visão geral

O projeto final é seu: escolha um problema real (de você, da família, de um comércio do bairro, de um grupo de estudo) e resolva com software, do zero até um link publicado. O que conta não é o tamanho, e sim mostrar que você sabe decidir, construir, testar e explicar.

Pré-requisitos: as trilhas que o seu projeto precisar, mais Carreira.

Requisitos

  • Um documento de requisitos de uma página: problema, quem usa, funcionalidades obrigatórias e desejáveis, e o que fica de fora.
  • Um modelo de dados, se houver persistência.
  • Testes das regras de negócio mais importantes.
  • Publicação com link funcionando.
  • Um README que explique o projeto para quem nunca o viu.

Etapas

  1. Escolha o problema conversando com quem o tem. Anote as dores com as palavras da pessoa.
  2. Escreva os requisitos e corte o escopo até caber em duas ou três semanas.
  3. Planeje a arquitetura: front-end, back-end, banco? Precisa mesmo de cada parte?
  4. Construa em fatias verticais: uma funcionalidade completa por vez, do banco à tela.
  5. Teste e peça feedback para alguém de fora.
  6. Publique e documente: como rodar, decisões técnicas, limitações e próximos passos.

  • Acessibilidade revisada com uma ferramenta automática e um teste manual pelo teclado.
  • Um vídeo curto apresentando o projeto.
