Java e Orientação a Objetos

Do primeiro programa às bases da orientação a objetos: tipos, controle de fluxo, classes e objetos, encapsulamento, herança, polimorfismo, interfaces, coleções e exceções.

Iniciante · 7 aulas · ~2 h de estudo

Seu progresso nesta trilha0/7

Módulo 1 · Fundamentos da linguagem

  1. 1Primeiro programa em Java: tipos e saída14 minpróximaTudo vive em classes, o programa começa no main e os tipos são fixos.
  2. 2Decisões, repetições e arrays15 minswitch com -> devolve valor; arrays vão de 0 a length - 1; textos se comparam com equals.

Módulo 2 · Orientação a objetos

  1. 3Classes, objetos e métodos16 minClasse é o molde; objeto é a instância; variáveis guardam referências.
  2. 4Encapsulamento e invariantes15 minDados privados; mudanças só por métodos que aplicam as regras.
  3. 5Herança, classes abstratas e polimorfismo17 minMesmo chamado, comportamento do tipo real do objeto.
  4. 6Interfaces e coleções17 minInterface é contrato; List, Set e Map resolvem a maioria dos problemas de dados.
  5. 7Exceções, records e boas práticas16 minTrate o que sabe tratar, nunca engula erros e use mensagens claras.
