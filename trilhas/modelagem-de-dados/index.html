Modelagem de Dados

Do levantamento de requisitos ao banco pronto: entidades, atributos, DER, cardinalidade, chaves, entidades fracas e associativas, normalização e dicionário de dados.

Iniciante · 8 aulas · ~2 h de estudo

Seu progresso nesta trilha0/8

Módulo 1 · Do problema ao modelo conceitual

  1. 1Requisitos e regras de negócio13 minpróximaModelar começa por entender o que precisa ser guardado e quais regras os dados devem respeitar.
  2. 2Entidades e atributos14 minEntidade é o que tem existência própria; atributo é uma característica dela.
  3. 3Relacionamentos, DER e cardinalidade15 minCardinalidade (mín,máx) diz se a participação é opcional e quantas ocorrências se ligam.
  4. 4N:N e entidade associativa15 minN:N vira uma tabela no meio com as duas chaves e os dados do próprio relacionamento.

Módulo 2 · Do modelo ao banco

  1. 5Chaves primárias, estrangeiras, compostas e substitutas16 minPK identifica cada linha; FK garante que as referências existem.
  2. 6Entidades fortes, fracas e associativas13 minA entidade fraca só existe e só é identificada junto com o dono.
  3. 7Do DER às tabelas: conceitual, lógico, físico e normalização18 minConceitual para conversar, lógico para estruturar, físico para o banco real.
  4. 8Dicionário de dados11 minA documentação que explica o significado de cada coluna e mantém o time alinhado.

Desafio final

Uma pergunta de cada aula da trilha. Bom para revisar antes de seguir para a próxima.
