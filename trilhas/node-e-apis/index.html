Trilhas / Node.js, HTTP e APIs

Node.js, HTTP e APIs

Do caminho de uma requisição pela internet até uma API REST com Express validada, segura, testada e publicada.

Intermediário · 8 aulas · ~2 h de estudo

Seu progresso nesta trilha0/8

Módulo 1 · Como a web funciona

  1. 1Como a web funciona: cliente, servidor e o caminho de uma requisição14 minpróximaCliente pede, servidor responde; DNS acha o endereço e TLS protege a conversa.
  2. 2HTTP na prática: métodos, status e cabeçalhos15 minMétodo é a intenção, status é o resultado, cabeçalhos dão o contexto.

Módulo 2 · Node.js

  1. 3Node.js: JavaScript fora do navegador15 minNode é um runtime de JavaScript com acesso a arquivos, rede e processos.
  2. 4Um servidor HTTP do zero com node:http18 minreq traz o pedido, res monta a resposta; toda requisição precisa de um res.end().

Módulo 3 · APIs com Express

  1. 5Express: rotas e middlewares16 minRotas respondem; middlewares rodam antes, em ordem, e chamam next().
  2. 6API REST: CRUD completo com validação20 minRecursos no plural, métodos como verbos, validação em toda entrada.
  3. 7Erros, variáveis de ambiente e segurança básica18 minMensagens claras para o cliente, detalhes só no log e segredos fora do código.
  4. 8Testando e publicando sua API17 minTeste sucesso e erros a cada mudança; publique com start, PORT e variáveis de ambiente.
