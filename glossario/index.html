Glossário

Os termos usados nas aulas, explicados em linguagem simples.

68 termos

AcessibilidadeWeb
Prática de fazer sites que funcionem para todas as pessoas, inclusive quem usa teclado ou leitor de tela.
Agente de IAIA
Sistema em que o modelo decide e executa passos usando ferramentas, como buscar dados ou chamar APIs.
AlgoritmoFundamentos
Sequência finita e precisa de passos que resolve um problema.
AlucinaçãoIA
Resposta da IA que parece correta, mas é inventada ou errada. Por isso respostas precisam ser verificadas.
APIBack-end
Interface que um sistema oferece para outros conversarem com ele.
async/awaitJavaScript
Forma de escrever código assíncrono como se fosse sequencial, esperando Promises com await.
AtributoDados
Característica de uma entidade, como o nome ou o CPF de um cliente.
AutenticaçãoBack-end
Confirmar quem a pessoa é (por exemplo, com login e senha).
AutorizaçãoBack-end
Decidir o que uma pessoa autenticada pode fazer.
Back-endBack-end
Parte do sistema que roda no servidor: regras, dados e segurança.
Banco de dadosDados
Sistema que guarda dados de forma organizada e permite consultá-los.
BooleanoFundamentos
Valor que só pode ser verdadeiro (true) ou falso (false).
Box modelWeb
Modelo em que todo elemento é uma caixa com conteúdo, padding, borda e margem.
BranchFerramentas
Linha de desenvolvimento separada no Git, para trabalhar sem afetar a principal.
CallbackJavaScript
Função passada como argumento para ser chamada depois.
CardinalidadeDados
Quantos elementos de uma entidade se relacionam com quantos da outra (1:1, 1:N, N:N).
Chave estrangeira (FK)Dados
Campo que aponta para a chave primária de outra tabela, criando a ligação entre elas.
Chave primária (PK)Dados
Campo (ou conjunto de campos) que identifica cada registro de forma única.
ClosureJavaScript
Função que continua acessando as variáveis do lugar onde foi criada.
CommitFerramentas
Registro de um conjunto de mudanças no histórico do Git, com uma mensagem.
CondicionalFundamentos
Estrutura que escolhe um caminho conforme uma condição, como if/else.
ConstanteFundamentos
Nome cujo valor não pode ser reatribuído depois de criado.
ContextoIA
Tudo o que o modelo recebe de uma vez: instruções, histórico e documentos. Tem um tamanho máximo.
CSSWeb
Linguagem que define a aparência das páginas: cores, tamanhos, espaços e layout.
Depuração (debug)Fundamentos
Processo de encontrar e corrigir a causa de um erro.
DERDados
Diagrama Entidade-Relacionamento: desenho de entidades, atributos, relacionamentos e cardinalidades.
DOMJavaScript
Representação da página como árvore de objetos que o JavaScript pode ler e alterar.
Elemento semânticoWeb
Tag que descreve o papel do conteúdo, como header, nav, main e article.
EntidadeDados
Algo do negócio sobre o qual o sistema precisa guardar informações, como CLIENTE ou PEDIDO.
Entidade associativaDados
Entidade criada para representar um relacionamento N:N e guardar seus atributos, como MATRÍCULA entre ALUNO e DISCIPLINA.
EscopoFundamentos
Região do código onde um nome pode ser usado.
EspecificidadeWeb
Peso de um seletor CSS que decide qual regra vence em um conflito.
EventoJavaScript
Algo que acontece na página, como um clique ou uma digitação, e que o código pode tratar.
FlexboxWeb
Sistema de layout do CSS para alinhar itens em uma dimensão (linha ou coluna).
Front-endBack-end
Parte do sistema que roda no navegador e que a pessoa vê e usa.
FunçãoFundamentos
Bloco de instruções com nome, que recebe parâmetros e pode devolver um resultado.
GitFerramentas
Sistema de controle de versão: guarda o histórico de mudanças do código.
GridWeb
Sistema de layout do CSS para organizar itens em linhas e colunas ao mesmo tempo.
HTMLWeb
Linguagem de marcação que descreve a estrutura e o significado do conteúdo de uma página.
HTTPBack-end
Protocolo de comunicação da web, com métodos (GET, POST...) e códigos de status.
Inteligência artificialIA
Área que cria sistemas capazes de realizar tarefas que associamos à inteligência humana, como reconhecer padrões e gerar texto.
JOINDados
Operação SQL que combina linhas de tabelas relacionadas.
JSONJavaScript
Formato de texto para trocar dados estruturados entre sistemas.
Laço (loop)Fundamentos
Estrutura que repete instruções enquanto uma condição for verdadeira, como for e while.
Modelo de linguagem (LLM)IA
Modelo treinado em muito texto que prevê a continuação mais provável de uma sequência de tokens.
MóduloJavaScript
Arquivo que exporta e importa partes do código, separando responsabilidades.
NormalizaçãoDados
Organização das tabelas para reduzir duplicação e evitar inconsistências.
npmFerramentas
Gerenciador de pacotes do Node.js: instala bibliotecas e roda scripts do projeto.
ParâmetroFundamentos
Nome, na declaração da função, que recebe um valor na chamada.
PromiseJavaScript
Objeto que representa um valor que vai chegar no futuro (ou um erro).
PromptIA
Instrução ou pergunta enviada ao modelo.
PseudocódigoFundamentos
Descrição de um algoritmo em linguagem simples, sem as regras de uma linguagem de programação.
Pull requestFerramentas
Pedido para revisar e juntar as mudanças de uma branch em outra, no GitHub.
RAGIA
Recuperação de informação: buscar trechos relevantes em documentos e entregá-los ao modelo junto com a pergunta.
ResponsividadeWeb
Capacidade de uma página se adaptar a telas de tamanhos diferentes.
RESTBack-end
Estilo de API que organiza recursos em endereços e usa os métodos HTTP para agir sobre eles.
RLSDados
Row Level Security: regras no banco que decidem quais linhas cada usuário pode ver ou alterar.
SeletorWeb
Parte de uma regra CSS que indica quais elementos recebem o estilo.
SintaxeFundamentos
Regras de escrita de uma linguagem.
SQLDados
Linguagem para consultar e alterar dados em bancos relacionais.
Status codeBack-end
Número que indica o resultado de uma requisição HTTP: 200 sucesso, 404 não encontrado, 500 erro no servidor.
TerminalFerramentas
Programa onde se digitam comandos de texto para o computador.
Tipo de dadoFundamentos
A natureza de um valor: texto (string), número, booleano, etc. Define o que se pode fazer com ele.
TokenIA
Pedaço de texto (parte de uma palavra, uma palavra ou um símbolo) que o modelo processa. Custos e limites são medidos em tokens.
VariávelFundamentos
Nome que guarda um valor na memória para ser usado ou alterado depois.
Variável de ambienteBack-end
Configuração fornecida ao programa de fora do código, ideal para segredos e endereços.
Vibe codingIA
Programar descrevendo o que se quer para uma IA, que escreve o código, enquanto a pessoa revisa, testa e direciona.
XSSJavaScript
Ataque em que um código malicioso é injetado em uma página, por exemplo via innerHTML com dados do usuário.
